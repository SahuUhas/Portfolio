## 📦 Installation

```bash
npm install
```



## ▶️ Run the Server

```bash
npm start
```

Your server will run at:

```
http://localhost:8080
```



## 🛠 Technologies Used

- Node.js  
- Express.js  
- HTML  
- CSS  
- JavaScript  



## 📌 How it Works

The Express server serves static files from the **HTML** folder:

```js
app.use(express.static(path.join(__dirname, "HTML")));
```

Default homepage loads:

```
HTML/sahu.html
```
